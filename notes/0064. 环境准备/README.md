### 3.1. 本地搭建 Playground 实验环境

如果你想要在本地搭建 Playground 实验环境，可以瞅瞅这章的笔记内容。

记录这一章节的目的主要也就是介绍快速搭建一个本地 React 学习环境的必要知识点。

本地实验环境更贴近我们真实开发 React 项目的实验环境，需要啥依赖就装啥依赖，需要啥工具（比如 VSCode 插件）就装啥工具。

### 3.2. 走官方的在线测试环境

这也是一个不错的选择，而且做法非常简单。

React 官方提供了一个非常现代且功能强大的官方 Playground，但它的定位和叫法与 Vue 有点不同。

在 React 全新的官方文档中，官方并没有使用一个单独的、名为 “Playground” 的独立域名网页，而是将 Playground（代码沙盒）完美地融进了整套官方文档的每一处示例中。

随意找一个文档中的代码示例，点击代码右上角的“Fork”按钮。

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs-2026@main/2026-06-10-11-32-12.png)

它会立刻为你打开一个基于 CodeSandbox 技术构建的官方模板沙盒。在这里你可以自由修改代码、添加文件、查看实时预览，并分享链接给他人。

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs-2026@main/2026-06-10-11-31-54.png)

如果只是一些小改动，想要快速测试验证想法，直接修改示例也是 ok 的。

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs-2026@main/2026-06-10-11-34-42.png)

如果要恢复原始示例，点击“Clear”。
