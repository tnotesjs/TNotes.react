## 2. 【AI】有哪些优质的 React 中文学习资源？

### 2.1. 官方资源（首选）

- React 中文文档
  - 官方维护的中文翻译
  - 与英文文档同步更新
  - 网址：https://zh-hans.react.dev
- React 官方博客中文翻译
  - 重要版本更新说明
  - 新特性深度解读

### 2.2. 技术博客与专栏

- 阮一峰的网络日志
  - React 入门教程系列
  - 浅显易懂，适合初学者
- Dan Abramov 博客中文翻译
  - React 核心团队成员
  - 深入理解 React 原理
- 掘金优质专栏
  - 搜索"React 进阶"、"React 源码解析"
  - 关注点赞数和评论质量

### 2.3. 视频教程

- 哔哩哔哩（B 站）
  - 大量免费 React 教程
  - 搜索"React 教程"、"React 实战"
  - 注意选择近期发布的视频
- 慕课网
  - 系统化的付费课程
  - 配套实战项目
- 极客时间
  - 专栏课程质量较高
  - 适合进阶学习

### 2.4. 技术书籍

- 《React 进阶之道》
- 《深入浅出 React 和 Redux》
- 《React 状态管理与同构实战》
- 《React 设计模式与最佳实践》

注意：选择书籍时注意出版时间，优先选择涵盖 React 16.8+ Hooks 内容的版本。
