## 4. 如何在社区中高效提问？

### 4.1. 提问前的准备

1. 搜索已有答案：先在社区内搜索相同或类似问题
2. 查阅官方文档：确认不是文档中已说明的基础问题
3. 本地调试：尝试自己解决，记录排查过程
4. 准备最小复现：提取问题核心，去除无关代码

### 4.2. 提问的正确方式

````md
❌ 错误提问示例：标题：React 报错了怎么办？内容：我的代码运行不了，求帮助！

✅ 正确提问示例：标题：useState 更新后组件未重新渲染的问题

内容：【环境信息】

- React 版本：18.2.0
- 开发工具：Vite 4.0
- 浏览器：Chrome 120

【问题描述】调用 setState 后，组件没有重新渲染，控制台无报错

【复现代码】

```tsx
function Counter() {
  const [count, setCount] = useState({ value: 0 })

  const increment = () => {
    count.value += 1 // ❌ 直接修改对象
    setCount(count)
  }

  return <button onClick={increment}>{count.value}</button>
}
```

【期望行为】点击按钮后数字应该增加

【已尝试的方案】

1. 检查了 useState 的导入
2. 确认事件绑定正确
````

### 4.3. 提问注意事项

- 使用清晰的标题，包含关键技术词汇
- 提供完整的环境信息和错误信息
- 格式化代码，使用代码块标记
- 描述已尝试的解决方案，避免伸手党
- 礼貌用语，感谢回答者的帮助

避免在多个平台重复发布相同问题，容易被视为灌水行为。

## 5. 如何参与开源社区贡献？

### 5.1. 贡献方式

- 文档翻译与勘误
  - 参与官方文档中文化
  - 修正翻译错误和表述问题
  - 适合新手入门开源贡献
- 编写技术文章
  - 分享学习笔记和实战经验
  - 帮助他人少走弯路
  - 建立个人技术影响力
- 回答社区问题
  - 在问答平台帮助他人
  - 巩固自己的知识体系
  - 积累社区声望
- 开源项目贡献
  - 修复 Bug 提交 PR
  - 开发新功能
  - 完善单元测试

### 5.2. 贡献流程示例

以参与 React 中文文档翻译为例：

1. Fork 官方文档仓库
2. Clone 到本地并创建新分支
3. 翻译或修正文档内容
4. 提交 PR 并等待 Review
5. 根据反馈修改完善
6. 合并到主分支

### 5.3. 贡献注意事项

- 遵循项目的贡献指南（CONTRIBUTING.md）
- 保持代码风格一致
- 编写清晰的提交信息
- 耐心等待 Maintainer 的 Review
- 接受建设性的反馈意见
