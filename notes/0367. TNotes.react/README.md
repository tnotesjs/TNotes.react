## 1. 本节内容

- TNotes.react 简介

TNotes.react 是一个用于记录 React 学习笔记的开源知识库。

目前记录的内容还比较杂乱，前期就是缺啥补啥！后续会计划找几份 React 的知名教程，参考它们的目录结构来重新优化 TNotes.react 的目录大纲。

## 2. 这份知识库使用的 React 版本是？

没有固定版本，知识库中记录的内容会随时更新，比如现在是 `2026.06`，对应的最新版是：`v19.2.7`，如果是此时写的笔记，就会按照这个版本走。

![img](https://cdn.jsdelivr.net/gh/tnotesjs/imgs-2026@main/2026-06-09-20-44-05.png)

在整理笔记时：

- 如果发现旧的写法在当前版本中无法使用，会及时更新笔记内容，加上必要的说明。
- 如果发现新版有更好地实现方式，也会同步更新笔记，加上必要的说明。
